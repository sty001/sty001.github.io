## 题 1：求第一次捐款总额与第三次捐款总额

**考察点**：awk 的字段引用（`$1` `$2` `$4`）、变量累加（`s+=$2`）、`BEGIN` 块输出表头与 `END` 块输出汇总结果——即 awk「读文件时逐行累加、读完一次性输出」的标准套路。

**实现思路**：数据格式是「姓名 第一次 第二次 第三次」，一行一个人。第一次是第 2 列（`$2`），第三次是第 4 列（`$4`，也就是最后一列 `$NF`）。所以：在 `BEGIN` 块打印表头，在主块对每行累加 `s1+=$2` 和 `s3+=$4`，在 `END` 块打印两个累加器。

### 步骤 1：构造测试数据（已实操）
{: .sec-ver}

```bash
mkdir -p /tmp/hw/day19 && cd /tmp/hw/day19
cat > donate.txt <<'EOF'
张三 100 200 300
李四 150 250 350
王五 200 300 400
赵六 50 80 120
孙七 500 600 700
周八 88 99 110
EOF
cat -n donate.txt
```

输出：

```console
$ cat -n donate.txt
     1	张三 100 200 300
     2	李四 150 250 350
     3	王五 200 300 400
     4	赵六 50 80 120
     5	孙七 500 600 700
     6	周八 88 99 110
```

6 个人，每人 3 次捐款，字段以空格分隔。第 1 列姓名、第 2 列第一次、第 3 列第二次、第 4 列第三次。

### 步骤 2：先看清列与累加过程（已实操）
{: .sec-prac}

正式写答案前，先把「取哪几列」和「累加是怎么进行的」明明白白打出来：

```bash
awk '{print $1, "第1次="$2, "第3次="$4}' donate.txt
awk '{s1+=$2; s3+=$4; print NR, $1, "s1="s1, "s3="s3}' donate.txt
```

输出：

```console
$ awk '{print $1, "第1次="$2, "第3次="$4}' donate.txt
张三 第1次=100 第3次=300
李四 第1次=150 第3次=350
王五 第1次=200 第3次=400
赵六 第1次=50 第3次=120
孙七 第1次=500 第3次=700
周八 第1次=88 第3次=110

$ awk '{s1+=$2; s3+=$4; print NR, $1, "s1="s1, "s3="s3}' donate.txt
1 张三 s1=100 s3=300
2 李四 s1=250 s3=650
3 王五 s1=450 s3=1050
4 赵六 s1=500 s3=1170
5 孙七 s1=1000 s3=1870
6 周八 s1=1088 s3=1980
```

第二条是理解 awk 累加的关键：`s1`/`s3` 是 awk 变量，未初始化时默认为 0，每读一行就往里加一次，读完全部 6 行后停在 `s1=1088`、`s3=1980`。这就是答案。awk 变量不用声明也能直接参与算术——空值当 0 用，这套「边读边算」能写这么短，根基就在这里。

### 步骤 3：标准答案——带表头输出（已实操）
{: .sec-best}

```bash
awk 'BEGIN{print "第一总额","第三次总额"} {s1+=$2; s3+=$4} END{print s1, s3}' donate.txt
```

输出：

```console
$ awk 'BEGIN{print "第一总额","第三次总额"} {s1+=$2; s3+=$4} END{print s1, s3}' donate.txt
第一总额 第三次总额
1088 1980
```

三个代码块的分工：

| 代码块 | 执行时机 | 执行次数 | 本题作用 |
| --- | --- | --- | --- |
| `BEGIN{...}` | 读文件**之前** | 1 次 | 打印表头「第一总额 第三次总额」 |
| `{...}`（主块） | 每读一行 | N 次（本题 6 次） | 累加 `s1+=$2`、`s3+=$4` |
| `END{...}` | 读文件**之后** | 1 次 | 打印两个累加器的最终结果 |

用 `column -t` 让两列对齐（已实操）：

```bash
awk 'BEGIN{print "第一总额","第三次总额"} {s1+=$2; s3+=$4} END{print s1, s3}' donate.txt | column -t
```

输出：

```console
$ awk 'BEGIN{print "第一总额","第三次总额"} {s1+=$2; s3+=$4} END{print s1, s3}' donate.txt | column -t
第一总额  第三次总额
1088      1980
```

这就是题目要求的最终形态：表头在上、数值在下、两列对齐。

### 步骤 4：表头对齐的三种写法（已实操）
{: .sec-prac}

`BEGIN` 里用 `printf "%-8s"` 想手工控宽时，中文表头容易与数字列错位——因为 gawk 在 UTF-8 locale 下按**字符数**补宽，而一个中文字符在终端占 **2 个显示列**。三种可落地的写法：

**写法 1：制表符分隔（最省事，推荐）**

```bash
awk 'BEGIN{print "第一总额\t第三次总额"} {s1+=$2; s3+=$4} END{print s1"\t"s3}' donate.txt
```

输出：

```console
$ awk 'BEGIN{print "第一总额\t第三次总额"} {s1+=$2; s3+=$4} END{print s1"\t"s3}' donate.txt
第一总额	第三次总额
1088	1980
```

制表符的跳格位置由终端按显示宽度计算，中文表头与数字会自动落到同一列。

**写法 2：交给 `column -t` 后处理（最稳）**

```bash
awk 'BEGIN{print "第一总额","第三次总额"} {s1+=$2; s3+=$4} END{print s1, s3}' donate.txt | column -t
```

**写法 3：`printf` 手工配平（表头比数值少 4 个字符宽度）**

```bash
awk 'BEGIN{printf "%-8s%-7s\n","第一总额","第三次总额"} {s1+=$2;s3+=$4} END{printf "%-12s%-12s\n",s1,s3}' donate.txt
```

输出：

```console
$ awk 'BEGIN{printf "%-8s%-7s\n","第一总额","第三次总额"} {s1+=$2;s3+=$4} END{printf "%-12s%-12s\n",s1,s3}' donate.txt
第一总额    第三次总额  
1088        1980        
```

配平规则：中文表头「N 个汉字」占 2N 个显示列但只算 N 个字符，所以表头的宽度参数要比数值列**小 N**（4 个汉字就小 4）。

### 步骤 5：三重交叉校验（已实操）
{: .sec-prac}

答案不能只信一条命令，换三条工具链分别算一遍：

```bash
# 校验 A：cut 取列 + awk 求和（换掉 awk 的列切分，验证列号没取错）
cut -d' ' -f2 donate.txt | awk '{s+=$1} END{print "第1次总额="s}'
cut -d' ' -f4 donate.txt | awk '{s+=$1} END{print "第3次总额="s}'

# 校验 B：纯 shell while 循环累加（完全不用 awk）
s1=0; s3=0
while read -r name a b c; do s1=$((s1+a)); s3=$((s3+c)); done < donate.txt
echo "第1次总额=$s1"; echo "第3次总额=$s3"

# 校验 C：grep -o 提取后求和
grep -o '^[^ ]* [0-9]*' donate.txt | awk '{s+=$2} END{print "第1次总额="s}'
```

输出：

```console
$ cut -d' ' -f2 donate.txt | awk '{s+=$1} END{print "第1次总额="s}'
第1次总额=1088
$ cut -d' ' -f4 donate.txt | awk '{s+=$1} END{print "第3次总额="s}'
第3次总额=1980

$ s1=0; s3=0
$ while read -r name a b c; do s1=$((s1+a)); s3=$((s3+c)); done < donate.txt
$ echo "第1次总额=$s1"; echo "第3次总额=$s3"
第1次总额=1088
第3次总额=1980

$ grep -o '^[^ ]* [0-9]*' donate.txt | awk '{s+=$2} END{print "第1次总额="s}'
第1次总额=1088
```

三条独立路径都得到 **1088** 和 **1980**，答案确认无误。别嫌麻烦，一条命令算出来的数，敢不敢直接写进报表，取决于你换过几条路子验它。

**验证方法**：①手工核算——第 1 次 `100+150+200+50+500+88 = 1088`，第 3 次 `300+350+400+120+700+110 = 1980`；②换工具链（cut/shell 循环）复算应得同一结果；③把数据改一行再跑，结果应同步变化（证明不是写死的常数）。

> **易错点**：
>
> - 列号数错：第 1 列是姓名 `$1`，第一次捐款是 `$2` 不是 `$1`；第三次是 `$4`，用 `$NF`（最后一列）更稳妥，列数变了也不受影响；
> - 表头放错位置：写进主块会每行都打印一次，必须用 `BEGIN`；
> - 结果放错位置：写进主块会打印 N 次中间值，必须用 `END`；
> - awk 变量不用预先声明、默认值为 0，但如果先用它做了字符串拼接就会变成字符串，累加前别混用；
> - `print s1, s3` 中间的逗号决定输出分隔符（默认空格，由 `OFS` 控制），写成 `print s1 s3` 会粘成 `10881980`；
> - 中文表头用 `printf "%-8s"` 对不齐，是因为按字符数补宽而非显示宽度，用 `\t` 或 `column -t` 规避。

> **参见**：[awk命令详解](/posts/linux-textproc-02/)、[sed命令详解](/posts/linux-textproc-01/)

## 扩展 1：求每个人的捐款总额（已实操）
{: .sec-ext}

**考察点**：awk 的 `for` 循环与 `NF`（当前行列数）配合，对「从第 2 列到最后一列」做不定长求和。

```bash
awk 'BEGIN{print "姓名\t总额"}{t=0; for(i=2;i<=NF;i++) t+=$i; print $1"\t"t}' donate.txt
```

输出：

```console
$ awk 'BEGIN{print "姓名\t总额"}{t=0; for(i=2;i<=NF;i++) t+=$i; print $1"\t"t}' donate.txt
姓名	总额
张三	600
李四	750
王五	900
赵六	250
孙七	1800
周八	297
```

要点：每行开始前必须把 `t` 重置为 0（awk 不会自动重置，不写 `t=0` 就会一直累加下去）；`NF` 是当前行的字段数（本题恒为 4），`for(i=2;i<=NF;i++)` 从捐款列循环到最后一列，这样即使有人捐了 5 次也能算对。

## 扩展 2：求每个人的捐款平均值（已实操）
{: .sec-ext}

```bash
awk 'BEGIN{print "姓名\t平均"}{t=0; for(i=2;i<=NF;i++) t+=$i; printf "%s\t%.1f\n", $1, t/(NF-1)}' donate.txt
```

输出：

```console
$ awk 'BEGIN{print "姓名\t平均"}{t=0; for(i=2;i<=NF;i++) t+=$i; printf "%s\t%.1f\n", $1, t/(NF-1)}' donate.txt
姓名	平均
张三	200.0
李四	250.0
王五	300.0
赵六	83.3
孙七	600.0
周八	99.0
```

捐款次数是 `NF-1`（总列数减去姓名列）。`printf "%.1f"` 保留 1 位小数，`%.2f` 保留 2 位，`%d` 取整。顺带一个精度坑：`%.1f` 是四舍五入，金额类对精度敏感的场合要么固定两位小数，要么把求和交给整数运算，别在小数位上裸奔。

## 扩展 3：找最大值（已实操）
{: .sec-ext}

```bash
# 全文件最大单笔捐款及所属人
awk 'BEGIN{max=0} {for(i=2;i<=NF;i++) if($i>max){max=$i; who=$1}} END{print "最大单笔: "max"  ("who")"}' donate.txt

# 每个人各自的最大单笔
awk '{m=$2; for(i=3;i<=NF;i++) if($i>m) m=$i; printf "%s\t最大=%s\n",$1,m}' donate.txt
```

输出：

```console
$ awk 'BEGIN{max=0} {for(i=2;i<=NF;i++) if($i>max){max=$i; who=$1}} END{print "最大单笔: "max"  ("who")"}' donate.txt
最大单笔: 700  (孙七)

$ awk '{m=$2; for(i=3;i<=NF;i++) if($i>m) m=$i; printf "%s\t最大=%s\n",$1,m}' donate.txt
张三	最大=300
李四	最大=350
王五	最大=400
赵六	最大=120
孙七	最大=700
周八	最大=110
```

求最大值的套路是「用第一个元素初始化 `m`，再逐个比较替换」。注意 `BEGIN{max=0}` 只在捐款都是正数时成立，若可能有负数要改用「首次赋值」的写法（`if(NR==1 || $i>max)`）。

## 扩展 5：awk 数组——按人汇总多行记录（已实操）
{: .sec-ext}

**考察点**：awk 数组（关联数组）是「按下标聚合」的核心工具，下标可以是字符串。前面的数据每人一行，用变量累加就够；如果数据变成**每人多行流水**，就必须用数组。

**实现思路**：构造一份「姓名 金额」的流水文件，同一个姓名出现多次，用 `a[$1]+=$2` 就能按姓名自动分桶累加，最后在 `END` 块用 `for(k in a)` 遍历输出。

### 步骤 1：构造流水数据（已实操）
{: .sec-prac}

```bash
cat > records.txt <<'EOF'
张三 100
李四 150
张三 200
王五 300
李四 250
张三 300
王五 400
赵六 50
EOF
cat -n records.txt
```

输出：

```console
$ cat -n records.txt
     1	张三 100
     2	李四 150
     3	张三 200
     4	王五 300
     5	李四 250
     6	张三 300
     7	王五 400
     8	赵六 50
```

### 步骤 2：按姓名累加（已实操）
{: .sec-prac}

```bash
awk '{a[$1]+=$2} END{for(k in a) print k, a[k]}' records.txt
```

输出：

```console
$ awk '{a[$1]+=$2} END{for(k in a) print k, a[k]}' records.txt
王五 700
赵六 50
李四 400
张三 600
```

一行 `a[$1]+=$2` 就完成了「按姓名分组求和」——数组下标 `$1` 是人名，值累加金额。第一次遇到某个名字时 `a[名字]` 从 0 开始，之后每次遇到同一个名字就往里加。awk 数组本质是关联数组（哈希表），下标按字符串存，所以统计套路就三板斧：**累加 `a[$1]+=$2`、计数 `c[$1]++`、多指标就并列开几个数组**，学会这三个能覆盖九成的分组统计需求。生产上大文件也优先用 awk 单遍跑完所有指标，别 `sort | uniq -c` 来回多趟读盘——awk 一次 IO 就把数全出齐了。

### 步骤 3：排序输出（已实操）
{: .sec-prac}

`for(k in a)` 的遍历顺序是 awk 内部哈希顺序，**不保证与文件顺序一致**（上面的输出就是 王五/赵六/李四/张三）。要稳定顺序就交给 `sort`：

```bash
awk '{a[$1]+=$2} END{for(k in a) print k, a[k]}' records.txt | sort
awk '{a[$1]+=$2} END{for(k in a) printf "%s\t%d\n",k,a[k]}' records.txt | sort -k2 -nr
```

输出：

```console
$ awk '{a[$1]+=$2} END{for(k in a) print k, a[k]}' records.txt | sort
张三 600
李四 400
王五 700
赵六 50

$ awk '{a[$1]+=$2} END{for(k in a) printf "%s\t%d\n",k,a[k]}' records.txt | sort -k2 -nr
王五	700
张三	600
李四	400
赵六	50
```

### 步骤 4：数组的两个经典用法（已实操）
{: .sec-prac}

```bash
# 统计出现次数（等价于 sort | uniq -c 的效果）
awk '{c[$1]++} END{for(k in c) print c[k], k}' records.txt | sort -rn

# 一次算出次数、合计、最大值三个指标
awk '{a[$1]+=$2; n[$1]++; if($2>m[$1]||m[$1]=="") m[$1]=$2} END{for(k in a) printf "%s\t次数=%d\t合计=%d\t最大=%d\n",k,n[k],a[k],m[k]}' records.txt | sort
```

输出：

```console
$ awk '{c[$1]++} END{for(k in c) print c[k], k}' records.txt | sort -rn
3 张三
2 王五
2 李四
1 赵六

$ awk '{a[$1]+=$2; n[$1]++; if($2>m[$1]||m[$1]=="") m[$1]=$2} END{for(k in a) printf "%s\t次数=%d\t合计=%d\t最大=%d\n",k,n[k],a[k],m[k]}' records.txt | sort
张三	次数=3	合计=600	最大=300
李四	次数=2	合计=400	最大=250
王五	次数=2	合计=700	最大=400
赵六	次数=1	合计=50	最大=50
```

**验证方法**：手工核对——张三出现 3 次（100+200+300=600，最大 300）、王五 2 次（300+400=700）、李四 2 次（150+250=400）、赵六 1 次（50）。用 `grep -c "张三" records.txt` 也能验证次数（应输出 3）。

## awk 核心知识点速查（本题用到与延伸）
{: .sec-ext}

### BEGIN / END 块执行时机（已实操）
{: .sec-prac}

```bash
awk 'BEGIN{print "BEGIN 执行 1 次"} {print "主块: 第"NR"行"} END{print "END 执行 1 次，共"NR"行"}' donate.txt
awk 'BEGIN{print "begin"} END{print "end"}' /dev/null      # 空输入也执行
```

输出：

```console
$ awk 'BEGIN{print "BEGIN 执行 1 次"} {print "主块: 第"NR"行"} END{print "END 执行 1 次，共"NR"行"}' donate.txt
BEGIN 执行 1 次
主块: 第1行
主块: 第2行
主块: 第3行
主块: 第4行
主块: 第5行
主块: 第6行
END 执行 1 次，共6行

$ awk 'BEGIN{print "begin"} END{print "end"}' /dev/null
begin
end
```

即使输入为空，`BEGIN`/`END` 也各执行一次——所以表头和汇总永远会被打印。

### 常用内置变量（已实操）
{: .sec-prac}

```bash
awk '{print "NR="NR, "NF="NF, "$1="$1, "$NF="$NF}' donate.txt | head -3
awk -F: '{print "用户="$1, "UID="$3, "shell="$NF}' <<< "root:x:0:0:/root:/bin/bash"
awk 'BEGIN{FS=":"; OFS=" | "}{print $1,$2,$3}' <<< "a:b:c"
awk '{print FILENAME" 第"FNR"行/累计"NR"行: "$1}' donate.txt records.txt | head -9
```

输出：

```console
$ awk '{print "NR="NR, "NF="NF, "$1="$1, "$NF="$NF}' donate.txt | head -3
NR=1 NF=4 $1=张三 $NF=300
NR=2 NF=4 $1=李四 $NF=350
NR=3 NF=4 $1=王五 $NF=400

$ awk -F: '{print "用户="$1, "UID="$3, "shell="$NF}' <<< "root:x:0:0:/root:/bin/bash"
用户=root UID=0 shell=/bin/bash

$ awk 'BEGIN{FS=":"; OFS=" | "}{print $1,$2,$3}' <<< "a:b:c"

$ awk '{print FILENAME" 第"FNR"行/累计"NR"行: "$1}' donate.txt records.txt | head -9
donate.txt 第1行/累计1行: 张三
donate.txt 第2行/累计2行: 李四
donate.txt 第3行/累计3行: 王五
donate.txt 第4行/累计4行: 赵六
donate.txt 第5行/累计5行: 孙七
donate.txt 第6行/累计6行: 周八
records.txt 第1行/累计7行: 张三
records.txt 第2行/累计8行: 李四
records.txt 第3行/累计9行: 张三
```

| 内置变量 | 含义 | 本题中的用法 |
| --- | --- | --- |
| `$0` | 整行内容 | 未直接使用 |
| `$1` `$2` … `$n` | 第 n 个字段 | `$2` 第一次捐款、`$4` 第三次捐款 |
| `NF` | 当前行字段总数 | `NF-1` = 捐款次数；`$NF` = 最后一列 |
| `NR` | 已读总行数（跨文件累计） | `END` 里报告总行数 |
| `FNR` | 当前文件内的行号 | 多文件处理时区分 |
| `FS` | 输入分隔符（默认空格/Tab） | `-F:` 或 `BEGIN{FS=":"}` |
| `OFS` | 输出分隔符（默认空格） | `BEGIN{OFS=" \| "}` 定制输出 |
| `FILENAME` | 当前文件名 | 多文件处理时标识来源 |

### 辨析：awk 里的变量与 shell 变量

两套变量长得像，规则完全不同：

- shell 取值要加 `$`（`$name`），awk 里写变量名就是取值（`s1`），`$s1` 反而是「取第 s1 列」——这是 awk 最常见的语法错误；
- awk 程序体习惯用单引号包裹，就是防 shell 抢先把 `$1`、`$2` 展开掉；
- 想把 shell 变量传进 awk，用 `-v` 选项：`awk -v limit=100 '$2>limit' donate.txt`，不要直接在程序体里拼字符串，引号一多必翻车。

### 条件过滤 + 累加（已实操）
{: .sec-prac}

```bash
awk '$2>100 {s+=$2; n++} END{print "符合人数="n, "合计="s}' donate.txt
```

输出：

```console
$ awk '$2>100 {s+=$2; n++} END{print "符合人数="n, "合计="s}' donate.txt
符合人数=3 合计=850
```

把条件写在主块前面（`模式{动作}`），只有满足条件的行才执行累加：第一次捐款 > 100 的有李四 150、王五 200、孙七 500，共 3 人合计 850。

### awk 数组速查
{: .sec-chk}

| 写法 | 作用 |
| --- | --- |
| `a[$1]+=$2` | 按 `$1` 分组累加 `$2` |
| `c[$1]++` | 按 `$1` 计数（等价 `uniq -c`） |
| `for(k in a) print k, a[k]` | 遍历数组（顺序不确定） |
| `if(k in a)` | 判断下标是否存在 |
| `delete a[k]` | 删除某个元素 |
| `length(a)` | 数组元素个数 |
| `a[$1]=a[$1]" "$2` | 按组拼接字符串 |

**验证方法**：数组汇总的结果可用 `grep -c "名字" 文件` 核对次数、用 `grep "名字" 文件 | awk '{s+=$2} END{print s}'` 核对合计，两者应与数组输出一致。

> **易错点**：
>
> - `for(k in a)` 遍历顺序是哈希顺序，不是文件顺序，需要有序输出必须接 `sort`；
> - 数组下标是字符串，`a[01]` 与 `a[1]` 是两个不同元素，数字下标要注意前导零；
> - 多行分组累加时忘了在每行开头重置临时变量（如 `t=0`），会导致跨行串数据；
> - `if($2>m[$1])` 在 `m[$1]` 未初始化时比较结果不可靠，要加 `|| m[$1]==""` 的首次赋值保护；
> - awk 里变量与字段引用不加 `$`（`$s1` 是取第 s1 列，`s1` 才是变量本身），这是最常见的语法错误；
> - `printf` 的中文宽度按字符数算不是显示宽度，中文表头与数字列对不齐时用 `\t` 或 `column -t`。

> **参见**：[awk命令详解](/posts/linux-textproc-02/)、[附录-命令速查表](/posts/linux-appendix-01/)

## 本篇小结
{: .sec-sum}

1. 本题标准答案一句话：`awk 'BEGIN{print "第一总额","第三次总额"} {s1+=$2; s3+=$4} END{print s1, s3}' donate.txt`，输出 1088 与 1980；`BEGIN` 打表头、`{}` 逐行累加、`END` 出结果，三个块的分工是 awk 求和类题目的通用骨架。
2. 列号要数清：`$1` 是姓名、`$2` 是第一次、`$4` 是第三次；用 `$NF` 取最后一列更抗变更。累加器变量无需声明，awk 默认初始化为 0。
3. 数要交叉校验才算数：本题用 `cut + awk`、纯 shell `while read` 循环、`grep -o` 三条独立路径复算，都得到 1088/1980；再手工核一遍 `100+150+200+50+500+88=1088`、`300+350+400+120+700+110=1980`。
4. 中文表头对齐是个坑：`printf "%-8s"` 按字符数补宽而中文占 2 个显示列，导致表头比数字列宽；解决办法是 `\t` 分隔、管道给 `column -t`、或表头宽度参数比数值列小「汉字个数」。
5. 不定长求和用 `for(i=2;i<=NF;i++) t+=$i`，记得每行开头 `t=0` 重置；求最大值用「首元素初始化 + 逐个比较」，有负数时要用 `NR==1` 或空值判断做首次赋值保护。
6. awk 数组解决「多行流水按人汇总」：`a[$1]+=$2` 按姓名分组求和、`c[$1]++` 计数，遍历用 `for(k in a)` 但顺序不确定，需要有序就接 `sort -k2 -nr`；一次性算次数/合计/最大值，就是三个数组并列使用。记住数组三板斧，九成的分组统计都不用愁。
