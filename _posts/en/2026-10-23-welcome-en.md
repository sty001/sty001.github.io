This is the first post on my blog, written to verify that the GitHub Pages + Jekyll (Chirpy theme) setup works end to end.

## What This Blog Will Cover

I will record my study and practice in the following areas here:

- **FPGA / Digital Circuits**: Quartus, Verilog, timing constraints, and more
- **EDA Toolchains**: Cadence, Keil, etc.
- **Web Full-Stack Development**: front end, back end, and deployment
- **AI / Large Language Models**: fine-tuning, deployment, Agent practice

## How to Write a New Post

Just create a new file under the `_posts/` directory, named `YYYY-MM-DD-title.md`, with Front Matter at the top:

```yaml
---
title: "Post Title"
date: 2026-10-23 12:00:00 +0800
categories: [Category]
tags: [Tag]
---
```

Then `git push` to the `main` branch — GitHub Actions builds and deploys to GitHub Pages automatically.
