| 主题 | 一句话结论 |
| --- | --- |
| 创建与写入 | `touch` 建空文件；`echo` 配合 `>` 覆盖、`>>` 追加，不打开文件直接写 |

### 知识卡片：目录与挂载 {: .sec-know}

| 主题 | 一句话结论 |
| --- | --- |
| 挂载本质 | 在内核挂载表登记"设备 X 挂到目录 Y"，之后对 Y 的访问转给设备 X |
| 挂载点 | 必须是已存在的空目录；挂载后原数据被遮住，卸载后恢复 |
| 卸载卡住 | `target is busy`，先退出挂载点目录，用 `fuser -m` / `lsof +D` 定位 |
| fstab 六列 | 设备（推荐 UUID）、挂载点、文件系统类型、挂载参数、dump（写 0）、fsck（根 1 其他 2 swap 0） |
| fstab 验证 | 改完必须 `mount -a` 不重启验证，写错直接重启可能开不了机 |
| FHS 分工 | `/etc` 配置不动、`/var` 日志轮转、`/tmp` `/run` 自动清、`/home` `/srv` 慎动、`/usr` `/bin` 绝不碰 |

## 题 3：vim 使用技巧

**考察点**：vim 的四种模式与切换、常用编辑命令、非交互用法与异常恢复。

**实现思路**：vim 是交互式全屏编辑器，交互按键无法在非终端环境演示，因此交互部分给出模式体系与命令表（B 级说明）；替换类命令用 sed 真跑等价逻辑（A 级），证明对"范围、标志位"的理解正确；最后给出 `vim -es` 非交互标准写法。

### vim 是什么 {: .sec-know}

- **vi**：Unix 上最经典的文本编辑器，类 Unix 系统几乎都自带；
- **vim**（Vi IMproved）：vi 的增强版，增加语法高亮、多级撤销、分屏、标签页等特性，是服务器上最常用的编辑器；CentOS 的 `vi` 命令实际由 vim-minimal 提供；
- **vim 与 sed**：vim 交互式全屏编辑，人一边看一边改；sed 非交互式流编辑器，按行处理适合写进脚本。vim 内部还能用 `:!sed` 调用外部命令，两者互补。

打开文件的方式：

```bash
vim file.txt          # 打开或新建文件
vim +10 file.txt      # 打开并跳到第 10 行
vim -R file.txt       # 以只读方式打开
```

### 四种模式及切换

| 模式 | 进入方式 | 特征 |
| --- | --- | --- |
| 普通模式（Normal） | 打开文件后的默认模式 | 每个键都是命令（移动、删除、复制） |
| 插入模式（Insert） | 按 `i` / `a` / `o` 等 | 左下角显示 `-- INSERT --`，敲键才是输入文本 |
| 可视模式（Visual） | 按 `v` / `V` / `Ctrl + v` | 先选中一片文本再执行操作 |
| 命令行模式（Command-line） | 按 `:` / `/` / `?` | 底部输入命令，回车执行后回到普通模式 |

模式切换的文字流程：

```text
普通模式 --按 i/a/o/I/A/O--> 插入模式 --按 Esc--> 普通模式
普通模式 --按 v/V/Ctrl+v--> 可视模式 --按 Esc--> 普通模式
普通模式 --按 : 或 / 或 ?--> 命令行模式 --按 Enter--> 普通模式
普通模式 --按 R--> 替换模式 --按 Esc--> 普通模式
```

记忆口诀：**Esc 是家**——不管在哪个模式，按 `Esc` 都能回到普通模式；**:wq 是门**——从普通模式进入命令行模式保存退出。

### 命令行模式替换：sed 等价真跑演示（已实操） {: .sec-ex}

vim 的替换命令格式为 `:[范围]s/旧内容/新内容/[标志]`，与 sed 的 `s` 命令同源（都源自 ex 行编辑器）。本机没有 vim，用 sed 真跑同一逻辑，验证对范围与标志位的理解。准备一个配置文件：

```bash
cd /tmp/hw/day8
printf 'old config 01\nkeep this line\nold config 02\nanother old value\n' > config.txt
cat -n config.txt
```

输出：

```console
$ cat -n config.txt   # 等价 vim :set number
     1	old config 01
     2	keep this line
     3	old config 02
     4	another old value
```

`:%s/old/new/g`（全文替换）的等价演示：

```bash
sed 's/old/new/g' config.txt
```

输出：

```console
$ sed 's/old/new/g' config.txt   # 等价 vim :%s/old/new/g
new config 01
keep this line
new config 02
another new value
```

`:2,3s/old/new/g`（只替换第 2 到 3 行）的等价演示：

```bash
sed '2,3s/old/new/g' config.txt
```

输出：

```console
$ sed '2,3s/old/new/g' config.txt   # 等价 vim :2,3s/old/new/g
old config 01
keep this line
new config 02
another old value
```

`:g/模式/d`（删除所有匹配行）的等价演示：

```bash
sed '/keep this line/d' config.txt
```

输出：

```console
$ sed '/keep this line/d' config.txt   # 等价 vim :g/keep this line/d
old config 01
old config 02
another old value
```

忽略大小写（vim 的 `i` 标志，GNU sed 用 `I`）的等价演示：

```bash
printf 'OLD value 1\nold value 2\n' > case.txt
sed 's/OLD/config/gI' case.txt
```

输出：

```console
$ sed 's/OLD/config/gI' case.txt   # 等价 vim :%s/OLD/config/gI
config value 1
config value 2
```

**验证方法**：四组真实输出分别验证四个知识点——全文替换每行都生效；范围替换只动指定行（第 1、4 行保持 `old`）；`:g/模式/d` 精确删除匹配行；忽略大小写标志让大小写混合内容全部命中。行号地址在 vim 与 sed 中一致（都从 1 开始）。

### 非交互写法：vim -es（预期输出）

vim 可以在脚本中非交互执行命令，格式为 `vim -es -c '命令1' -c '命令2' 文件`（`-e` ex 模式，`-s` 静默）。真机执行：

```bash
vim -es -c '%s/old/new/g' -c 'wq' config.txt
cat config.txt
```

预期行为：vim 静默打开文件、执行全文替换、保存退出，`cat` 看到的内容与上面 sed 演示一致。适合写在部署脚本里改配置，但批量处理文件的场景优先用 sed/awk——不要用 vim 做本该由脚本完成的事（比如在 vim 里逐行 `dd`，不如一条 `sed` 或 `grep -v`）。

### 异常处理：swap 文件报错（预期输出） {: .sec-ts}

异常退出（断电、强制关终端）后，交换文件 `.swp` 残留，下次打开报错：

```console
（预期输出，CentOS 7）
E325: ATTENTION
found a swap file by the name ".config.txt.swp"
Swap file ".config.txt.swp" already exists!
[O]pen Read-Only, (E)dit anyway, (R)ecover, (D)elete it, (Q)uit, (A)bort:
```

| 选项 | 含义 | 适用场景 |
| --- | --- | --- |
| `O` | 只读方式打开 | 只想查看内容，不做修改 |
| `E` | 直接编辑，忽略交换文件 | 确认没有其他 vim 进程在编辑 |
| `R` | 恢复交换文件中的内容 | 上次异常退出，想找回未保存修改 |
| `D` | 删除交换文件后正常打开 | 确认不需要恢复 |

处理前先用 `ls -la .config.txt.swp` 确认没有另一个用户或终端正在编辑同一文件（生产服务器上可能是他人误操作）。平时正常用 `:wq` 退出，交换文件会自动清除。

> **易错点**：一是模式混淆——不知道自己在哪个模式、改错后无法退出，先按 `Esc` 回普通模式再 `:q!`；二是从别处粘贴的代码缩进全乱——autoindent 与粘贴内容缩进叠加，粘贴前 `:set paste`、粘贴后 `:set nopaste`；三是保存报 `E45: 'readonly'`——当前用户没有写权限，换账号或用 `:w !sudo tee %` 借 sudo 保存。

> **参见**：文档编辑软件使用技巧、常用文件操作命令、sed 命令详解

## 自测 {: .sec-prac}

1. vim 中从插入模式返回普通模式按什么键？保存退出和不保存退出分别用什么命令？
2. 删除光标所在行及其下方共 4 行，命令是什么？复制当前行并粘贴到下一行呢？
3. 把文件中所有 `old` 替换为 `new` 且每处都要求确认，命令是什么？
4. 打开文件提示 `found a swap file` 是什么原因？怎么处理？
5. vim 与 sed 的核心区别是什么？批量替换 100 个文件该用哪个？

> **参考答案：** 1. 按 `Esc`；保存退出 `:wq`（或 `ZZ`），不保存退出 `:q!`（或 `ZQ`）。2. `4dd`（次数+删除符）；`yy` 复制当前行、`p` 粘贴到下一行。3. `:%s/old/new/gc`。4. 上次异常退出残留了交换文件（或该文件正被其他 vim 进程编辑）；先 `ls -la` 确认无其他编辑者，再选 `R` 恢复或 `D` 删除。5. vim 是交互式全屏编辑器需要人实时操作，sed 是非交互式流编辑器适合脚本；批量替换用 sed（`sed -i 's/old/new/g' 文件`）。

## 本篇小结 {: .sec-sum}

1. 八天知识可归为六大主题：虚拟化与远程连接、命令基础、文件操作、目录与挂载、系统文件与运行级别、别名与 history，每块都能浓缩成几句可复述的结论。
2. 命令记忆按功能归类：系统运行（shutdown/reboot/runlevel）、目录路径（ls/mkdir/cd/pwd）、文件操作（touch/echo/cat/head/tail/cp/mv/rm/rmdir）、重定向与通配符、链接（ln）、快捷方式与别名（Tab/history/!!/!$/alias）、挂载（mount/umount/blkid/df）。
3. vim 四种模式：普通、插入、可视、命令行；`Esc` 永远回到普通模式，`:wq` 保存退出，`:q!` 不保存退出。
4. 替换命令 `:%s/旧/新/g` 与 sed 同源，范围用行号（`:2,3s/...`）、确认用 `c`、忽略大小写用 `i`；行号地址两者一致。
5. vim 交互编辑、sed/awk 脚本批处理，分工明确；`vim -es -c` 可非交互执行，但批量场景优先 sed。
6. 异常恢复三招：`:e!` 放弃修改重载、`:recover` 崩溃恢复、E325 时确认无其他编辑者后 `R`/`D`。
