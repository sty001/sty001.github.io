Une collection de blogs techniques, de projets open source et de la boîte à outils quotidienne d'un ingénieur hardware : **ressources d'apprentissage / recherche de datasheets / distribution de composants / chaîne EDA**. Échangeons volontiers des liens — commentez sous un article ou écrivez-moi.

## Blogs techniques / Communautés

- [Thème Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) — le thème Jekyll de ce blog
- [Ruan Yifeng's Weblog](https://www.ruanyifeng.com/blog/) — un blog de développeur classique du web chinois
- [Liao Xuefeng](https://www.liaoxuefeng.com/) — tutoriels Python / Git / JavaScript
- [Mr-Wu's Blog](https://www.mr-wu.cn/) — embarqué / matériel : analyses détaillées
- [BookStack](https://www.bookstack.cn/) — une belle plateforme de documentation / livres en ligne
- [TruthHun](https://github.com/truthhun) — auteur de BookStack, passionné d'open source

## Ressources d'apprentissage hardware

- [Luat Docs](https://docs.openluat.com/) — l'un des centres de documentation 4G / Cat.1 / GNSS les plus complets
- [Xiaomeige FPGA](https://fpga.cn/) — enseignement FPGA et projets pratiques
- [OSHWHub](https://oshwhub.com/) — communauté de hardware open source (écosystème LCSC EDA)
